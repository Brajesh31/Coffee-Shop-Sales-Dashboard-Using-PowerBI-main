# 🐞 Bug Reporting

## Purpose
A useful issue states affected PBIX/workbook version, environment, page/query/measure, date/filter context, reproduction steps, expected behavior, actual behavior, and business impact.

## Current project context
For calculation defects include the measure name and an independent expected value. For source defects include the source object and sanitized example. For visual defects include a genuine safe screenshot.

## Recommended workflow
Do not post customer data, credentials, private workspace links, or exploit details publicly. Use SECURITY.md for vulnerabilities.

## Evidence and verification
Keep the defect reproducible and distinguish suspected cause from confirmed root cause.
