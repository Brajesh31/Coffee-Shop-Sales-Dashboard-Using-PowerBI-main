# 📋 Functional Requirements

## Purpose
FR-01: open the supplied PBIX in a compatible Power BI Desktop environment. FR-02: resolve the workbook source path when prompted. FR-03: refresh without unexplained query errors. FR-04: show the sales, order, and quantity analysis described by the project. FR-05: support documented comparisons. FR-06: apply filters consistently with intended model relationships. FR-07: display units, periods, and titles clearly. FR-08: allow a reviewer to reconcile key totals.

## Current project context
Filter controls, cross-highlighting, bookmarks, drill-through, tooltip pages, reset actions, and page navigation are items to inspect, not confirmed behavior until tested in the PBIX.

## Recommended workflow
For each requirement, record preconditions, exact user action, expected result, actual result, and evidence. Accept a requirement only after testing in the relevant Power BI environment.

## Evidence and verification
These requirements do not introduce transaction capture, customer accounts, inventory updates, APIs, or administrative screens.
