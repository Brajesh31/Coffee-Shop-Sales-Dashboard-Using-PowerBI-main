# 📐 Code and Artifact Standards

## Purpose
The repository combines Power BI binary artifacts with text documentation, SVG illustrations, YAML issue forms/workflows, and a Python validator.

## Current project context
Use descriptive names for measures, pages, queries, and source objects. Keep number formats and business definitions consistent. Use explicit units, clear titles, and meaningful alt text. For Markdown, use hierarchical headings, concise tables, valid relative links, and evidence-based statements. For Python, use clear functions, type hints where helpful, and non-zero exit codes for failed checks.

## Practical process
Do not claim standards are already satisfied across the PBIX until its internals are inspected. Review changed content against the applicable data, visual, accessibility, and security guides.

## Verification and boundaries
No JavaScript, TypeScript, SQL, or CSS style guide is applicable to the current project files.
