# 🧪 Accessibility Testing and Audit

## Purpose
Review every page for keyboard access, focus order, title hierarchy, alt text, chart labels, table alternatives, contrast, colour dependence, visual density, and zoom behavior.

## Current project context
The PBIX must be tested in the target Power BI environment. Documentation does not confirm accessibility properties.

## Recommended workflow
Record page, visual, issue, assistive technology, environment, expected behavior, observed behavior, severity, screenshot/test note, owner, and retest. Mark a defect resolved only after retesting.

## Evidence and verification
Use the accessibility audit template and update accessibility.md when report behavior changes.
