# 📱 Responsive and Small-screen Behavior

## Purpose
This is not a responsive web application. Power BI uses canvas sizing and may support phone layouts depending on how the PBIX was authored.

## Current project context
A desktop report does not prove that a phone layout exists. Mobile behavior has not been verified.

## Recommended workflow
Test the report at its intended page size, fit-to-width, browser viewing if published, and narrow viewport. If a phone layout exists, record which visuals are included, omitted, or reordered.

## Evidence and verification
Do not claim a mobile-optimized experience until each relevant page is inspected.
