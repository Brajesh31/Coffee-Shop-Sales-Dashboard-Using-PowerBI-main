# 🔊 Screen Reader Support

## Purpose
Screen-reader support depends on report titles, visual alt text, semantic labels, table structures, reading order, and the capabilities of the Power BI viewing environment.

## Current project context
The PBIX alt text and screen-reader behavior have not been audited. No custom accessible web component code exists in this repository.

## Practical process
Add informative alt text to meaningful visuals, use descriptive titles, provide data tables where appropriate, avoid ambiguous labels, and test the report with a supported screen reader. Record environment, page, visual, output spoken, and barriers.

## Verification and boundaries
Do not claim that all report visuals are screen-reader friendly without testing.
