# 🧶 Report Design System

## Purpose
Create a consistent visual language for the Power BI canvas without guessing the existing theme.

## Current project context
The repository includes a background image, but exact theme colours, typography, visual styles, page size, and spacing have not been extracted.

## Recommended workflow
Document verified theme colours, semantic states, background/surface colours, font family, title/body sizes, number formats, border treatment, and chart defaults from the actual PBIX. Reuse these tokens across cards, charts, labels, and conditional formatting.

## Evidence and verification
Do not select colours solely because they suit a coffee theme. Check contrast and colour-blind-safe distinctions. Export a theme JSON only after verifying it matches the report.
