# ☕ Product Overview

## 🎯 Purpose
The Coffee Shop Sales Dashboard is a business-intelligence portfolio project built with Microsoft Power BI. Its stated purpose is to help explore coffee shop sales performance through time, store, category, and product views.

## 👥 Intended audience
| Persona | Questions they may investigate |
|---|---|
| Store manager | How are sales and order volumes changing? |
| Operations lead | Are there recurring high-demand day/hour periods? |
| Inventory planner | Which products or categories appear in leading sales rankings? |
| Business analyst | How do locations, time periods, and categories compare? |
| Portfolio reviewer | How do Excel, Power Query, DAX, and Power BI fit together? |

These are intended users inferred from the analytical scope, not confirmed research participants.

## 🧩 Problem and proposed value
Raw transactional data is difficult to interpret quickly. A consolidated report can make trends, comparisons, and concentrations visible. The existing project overview identifies monthly KPIs, daily trends, store and category comparisons, top products, and day-hour patterns.

## ✅ Scope
Included artifacts:
- Power BI report file.
- Excel source workbook artifact.
- Background image asset.
- Documentation and validation support.

Described analysis:
- Sales, orders, and quantity.
- Month-over-month change.
- Weekday and weekend comparison.
- Store location and product category analysis.
- Daily sales and average reference.
- Top-ten product ranking.
- Day-hour sales, order, and quantity matrix.

## 🚧 Not established by repository
The repository does not establish an online ordering system, payment processing, inventory management platform, API, live data warehouse, or automated Power BI Service deployment.

## 📏 Success criteria
1. Report opens reliably in Power BI Desktop.
2. Report refreshes from the documented workbook source.
3. KPI totals reconcile to documented source tests.
4. Visuals present clear labels, units, and time context.
5. Comparisons match the described analytical scope.
6. Documentation matches the actual PBIX.
