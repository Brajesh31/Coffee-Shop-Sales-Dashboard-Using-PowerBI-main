# 🤝 Contributor Guide

## Purpose
Contributions can improve report accuracy, data definitions, visual usability, accessibility, refresh guidance, diagrams, and documentation.

## Current project context
Modify PBIX and XLSX only in working copies. Read the scope and security policy, identify the business question, inspect the relevant query/model/visual, validate results, update documentation, run repository checks, and submit a focused change.

## Recommended workflow
Use root CONTRIBUTING.md for Git workflow and developer-guide.md for report-specific technical work.

## Evidence and verification
Include actual QA evidence and list anything that could not be tested.

## Related documentation
Use the [documentation index](README.md) to find related data, architecture, security, QA, and operations guidance.
