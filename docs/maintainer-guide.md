# 🧰 Maintainer Guide

## Purpose
Maintainers protect report/source artifacts, keep project scope accurate, review model and visual changes, manage data exposure, maintain GitHub automation, and keep documentation current.

## Current project context
The maintainer owns the release decision. This repository does not establish an automated Power BI Service release pipeline.

## Recommended workflow
Before release, verify data rights and classification, refresh the PBIX, reconcile measures, inspect report pages, test interactions, review accessibility, save rollback copies, update changelog/status, and check workflow permissions.

## Evidence and verification
Keep unresolved PBIX details in known-issues.md. Do not convert uninspected behavior into implementation facts.
