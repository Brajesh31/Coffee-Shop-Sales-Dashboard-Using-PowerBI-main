# 🎛️ Design Tokens

## Purpose
The report's current theme values have not been extracted. This page defines which values should be recorded, not the palette already in use.

## Current project context
Capture primary/secondary colors, background and surface colors, semantic status colors, font family, title/body sizes, spacing, line/border treatment, number formats, and chart defaults from the real PBIX or approved theme file.

## Practical process
Store exact tokens in a table with token name, value, intended use, contrast check, and source evidence. Update the table whenever the theme changes. Avoid encoding meaning by color alone.

## Verification and boundaries
The new repository banner uses an illustrative warm coffee palette. That palette must not be represented as the dashboard's actual theme without PBIX inspection.
