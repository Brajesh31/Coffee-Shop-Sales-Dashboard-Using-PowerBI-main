# 💻 Installation Guide

## Purpose
This is a desktop-authored Power BI project. The primary setup dependency is a compatible Windows environment with Microsoft Power BI Desktop and access to the committed Excel workbook.

## Current project context
Download or clone the repository. Preserve the PBIX and XLSX together. Install Power BI Desktop from Microsoft's official distribution channel. Verify that the report opens before changing source settings. If Power BI requests a source path, inspect the Power Query source step and select the repository's workbook copy.

## Practical process
Record Power BI Desktop version, Windows version, workbook version, locale, and any custom visuals or connectors discovered in the PBIX. Keep installation instructions vendor-current and do not bundle installers in this repository.

## Verification and boundaries
No Node.js, npm, Java, PHP, database server, Docker runtime, or application package installation is needed for the visible project.
