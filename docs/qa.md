# 🧪 Quality Assurance

## Purpose
QA covers source workbook integrity, query refresh, model relationships, KPI reconciliation, visual rendering, interactions, accessibility, security, and documentation links.

## Current project context
A report is not QA-passed merely because it opens. Each release should state PBIX/workbook version, environment, test results, known issues, and reviewer.

## Recommended workflow
Run source checks, refresh, relationship checks, KPI reconciliation, filter tests, report-page review, accessibility/security checks, and repository validation. Record skipped or blocked tests honestly.
