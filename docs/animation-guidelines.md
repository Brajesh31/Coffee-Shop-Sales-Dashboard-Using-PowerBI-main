# ✨ Animation and Motion Guidelines

## Purpose
This is a Power BI report, not an animated web application. Motion should not distract from reading values or create an illusion of live updates.

## Current project context
No custom animated components or animation configuration has been verified in the PBIX.

## Practical process
Prefer stable transitions and avoid automatic movement or flashing visuals. If a Power BI visual or embedded asset animates, document the purpose, user control, duration, and reduced-motion alternative where the hosting environment supports it.

## Verification and boundaries
No animation package or motion design system is present in the repository.
