# ⚫ Color Contrast

## Purpose
Text and non-text chart elements should remain distinguishable against their backgrounds. Status should not be conveyed by color alone.

## Current project context
Actual foreground/background combinations have not been inventoried from the PBIX.

## Practical process
Record each text and visual pair, intended role, measured contrast, and remediation. Review KPI cards, axes, labels, matrix conditional formatting, and selected/unselected slicer states. Add symbols, text, or patterns to reinforce meaning.

## Verification and boundaries
Use an applicable WCAG contrast target during review, but do not claim conformance from a sample of colors alone.
