## 🐛 Reporting a problem

Open a GitHub issue and include:

- Operating system and Power BI Desktop version.
- Whether the PBIX opens successfully.
- The exact error text, with secrets and private paths removed.
- Steps to reproduce.
- Whether the workbook is present and accessible.
- The report page, visual, or metric involved.
- A screenshot with sensitive values hidden, if relevant.

## 📊 Questions about a metric

Include the metric name, filters applied, date range, expected result, actual result, and why the expected value is correct. A business definition is more useful than a screenshot alone.
