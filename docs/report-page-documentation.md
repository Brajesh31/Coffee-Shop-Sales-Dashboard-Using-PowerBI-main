# 🗺️ Report Page Documentation Standard

## Purpose
For each actual PBIX page capture exact name, title, business question, canvas size, visual inventory, measure, dimensions, slicers, interactions, sorting, tooltip/drill actions, accessibility text, and screenshot path.

## Current project context
The README's feature categories are not proof of separate pages. The PBIX page inventory remains to be completed through Power BI Desktop inspection.

## Recommended workflow
Create one record per actual page and update it whenever visuals or navigation change. Keep hidden pages and tooltip pages in the inventory and distinguish them from primary report pages.

## Evidence and verification
Never present a conceptual mockup as a screenshot of the report.
