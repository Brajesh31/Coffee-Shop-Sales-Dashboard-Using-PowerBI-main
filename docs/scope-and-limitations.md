# 🚧 Scope and Limitations

## Purpose
In scope: Power BI report artifact, Excel workbook artifact, background image, report-level sales analysis described by the README, documentation, diagrams, and repository validation support.

## Current project context
Out of scope in the visible repository: transaction processing, payments, inventory management, customer identity, order fulfillment, APIs, database hosting, forecasting models, and verified Power BI Service operations.

## Recommended workflow
Review scope whenever artifacts change. Record any new connector, metric, page, or deployment target with supporting evidence. Update limitations and roadmap when a capability is implemented and tested.

## Evidence and verification
A PBIX does not prove a Service workspace, gateway, scheduled refresh, row-level security, or public embed. An XLSX does not prove anonymization or redistribution permission.
