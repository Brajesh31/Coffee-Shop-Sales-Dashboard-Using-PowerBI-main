# ⚙️ Configuration Guide

## Purpose
The main configuration points are expected inside the PBIX and Power Query source settings: workbook path, source connection settings, parameters, model relationships, filters, and report visual settings.

## Current project context
Exact parameter names and actual source paths have not been inspected. No application configuration file or runtime config directory is visible.

## Recommended workflow
When moving the project, keep the PBIX and workbook in a known local folder, inspect the Power Query source step, update only the path or approved settings, apply changes, refresh, and save a separate working copy. Document each verified setting and its effect.

## Evidence and verification
Never publish private local paths, tenant IDs, passwords, or tokens in examples or screenshots.
