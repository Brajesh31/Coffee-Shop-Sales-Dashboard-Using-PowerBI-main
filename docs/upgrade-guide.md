# ⬆️ Upgrade Guide

## Purpose
Use this guide for planned Power BI Desktop, workbook, connector, custom visual, or report-model upgrades. For structural migrations, pair it with migration-and-upgrade.md.

## Current project context
Before upgrading, retain the old PBIX and matching workbook, capture key results, and record the current environment. Upgrade a working copy first.

## Practical process
After upgrade, check report open, refresh, source compatibility, relationship behavior, measures, filters, visuals, accessibility, and performance. Record all differences and preserve a rollback path.

## Verification and boundaries
Do not publish a new minimum version until it has been tested on the intended maintainer environment.
