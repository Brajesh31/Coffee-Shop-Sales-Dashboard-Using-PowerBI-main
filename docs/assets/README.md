# 🖼️ Documentation Assets

This folder contains original explanatory graphics.

## Asset policy
- Use real Power BI screenshots only for actual report imagery.
- Use SVG for diagrams that should remain sharp.
- Add meaningful alt text in Markdown.
- Keep graphics relevant to coffee-shop analytics.
- Do not use stock imagery as evidence of functionality.
- Do not include private data, credentials, or workspace URLs.

## Subfolders
- `diagrams/`: architecture and workflow graphics.
- `screenshots/`: reserved for verified screenshots captured from Power BI Desktop.

The original `Background image.png` remains in the repository root.
