# 📦 Release Management

## Purpose
A report release is a matching PBIX and source workbook version with verified documentation and QA evidence.

## Current project context
Before release, freeze the source copy, refresh and reconcile critical KPIs, inspect report pages, confirm access/data classification, capture genuine screenshots, update changelog/status, and record commit and file hashes.

## Recommended workflow
For Service publishing, record workspace, report URL classification, owner, credentials, refresh configuration, gateway dependency, permissions, and rollback plan. Do not publish private URLs publicly.
