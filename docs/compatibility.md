# 🖥️ Compatibility Matrix

## Purpose
The expected authoring environment is Power BI Desktop on Windows. The minimum supported Desktop build, tested Excel version, browser experience, and mobile behavior are not recorded.

## Current project context
For each release, record Power BI Desktop build, Windows version, Excel compatibility, source workbook version, locale, date settings, and any custom visual dependency found in the PBIX.

## Recommended workflow
Test open, refresh, core KPIs, visual rendering, and export behavior on the intended environment. Document the tested combination rather than claiming universal compatibility.

## Evidence and verification
Do not claim native macOS, mobile app, or Power BI Service compatibility without an actual test.
