# ☕ Project Background

## Purpose
This repository is a Power BI portfolio project for exploring historical coffee-shop sales. The repository contains a PBIX report/model artifact, an Excel workbook, and a visual background asset. It is not a point-of-sale or store-management application.

## Current project context
The existing project overview describes analysis of sales, orders, quantity, store locations, product categories, top products, and time patterns. It does not establish store policies, costs, margins, customer profiles, or staffing rosters.

## Recommended workflow
Preserve the reporting question when changing a chart. Record selected periods and filters behind each finding. Separate observed data from hypotheses about causes. Confirm source provenance and redistribution rights before sharing data.

## Evidence and verification
The artifact inventory verifies that the PBIX, XLSX, and image exist. Other business context must come from an approved data owner, not assumptions based on the project name.
