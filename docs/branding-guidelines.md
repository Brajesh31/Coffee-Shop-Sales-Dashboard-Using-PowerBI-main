# ☕ Branding and Visual Asset Guidelines

## Purpose
Use the project name consistently and prefer coffee-and-analytics imagery over unrelated stock visuals. Keep text contrast strong and all images meaningfully described.

## Current project context
The existing PNG is a repository background asset. The new banner, logo, and SVG diagrams are original explanatory illustrations, not screenshots of the PBIX.

## Recommended workflow
Use SVG for scalable marks and architecture illustrations, PNG for genuine screen captures, and alt text that explains an image's purpose. Remove sensitive information from captures. Maintain a consistent visual identity without implying that the same palette is already used in the report.
