# 📊 Project Risk Register

## Purpose
Risk categories include source schema drift, incorrect KPI semantics, refresh failure, binary artifact mismatch, public data exposure, confusing filters, inaccessible visuals, unreviewed workflow actions, and loss of a known-good artifact.

## Current project context
For each risk record cause, consequence, likelihood, impact, score, control, residual risk, response, owner, and review date. Link mitigations to QA and security guides.

## Recommended workflow
Risk scores require owner judgment and evidence; no arbitrary severity is pre-filled.

## Evidence and verification
Review this register when the source, report, workflows, or distribution model changes.
