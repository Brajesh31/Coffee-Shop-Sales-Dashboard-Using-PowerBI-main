# 🎨 Report UI and UX Guidelines

## Purpose
Each report page should communicate one primary business question. Use clear titles, visible date context, consistent number formats, readable labels, sensible sorting, and accessible colour encoding.

## Current project context
The actual page layout, slicers, theme, font sizes, navigation controls, and interactions have not been extracted from the PBIX. Background image.png is a visual asset, not proof of a complete design system.

## Recommended workflow
Review visual hierarchy, chart choice, axis scale, tooltip clarity, filter discoverability, empty states, and reading order. Capture real screenshots only after opening the PBIX.

## Evidence and verification
Do not claim a website component system or responsive frontend. See design-system.md and accessibility.md.
