## Asset rules
- Add alt text to Markdown images and descriptive titles/descriptions to SVGs.
- Prefer SVG for diagrams and scalable illustrations.
- Use genuine Power BI captures for report screenshots; never present mockups as actual pages.
- Remove sensitive data, private workspace names, tenant IDs, and credentials before committing screenshots.
- Keep diagrams aligned with current architecture and label optional flows clearly.
