# 📖 Glossary

| Term | Meaning |
|---|---|
| BI | Business intelligence |
| DAX | Data Analysis Expressions, the calculation language used by Power BI |
| ETL | Extract, transform, load |
| KPI | Key performance indicator |
| MoM | Month over month |
| PBIX | Power BI Desktop report file format |
| Power Query | Data connection and transformation experience used by Power BI |
| Semantic model | Tables, relationships, measures, and metadata used by the report |
| Filter context | Filters that affect a DAX calculation |
| Cross-filtering | An interaction where one visual filters another |
| Grain | What one row or aggregated record represents |
| Data lineage | Trace from source through transformations and calculations to output |
| Reconciliation | Comparing a result with an independent expected value |
| Gateway | Component used by Power BI Service to access certain on-premises sources |
| Refresh | Re-evaluation and loading of source data into the model |
