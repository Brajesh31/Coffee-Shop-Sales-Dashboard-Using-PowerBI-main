# 📚 Data Dictionary and Source Profiling

## Purpose
The source artifact is Coffee Shop Sales.xlsx. Sheet names, named tables, field names, row count, date coverage, null counts, and key constraints have not been extracted from the binary workbook in this documentation pass.

## Current project context
For every source sheet/table, record its grain, column name, business meaning, data type, safe example, null policy, uniqueness expectation, sensitivity classification, transformation, and downstream measures. Profile row counts, duplicate keys, invalid dates, negative values, and category distributions.

## Recommended workflow
Capture results from Excel or Power Query and update this guide whenever source schema changes. Do not expose customer-identifying values in examples. Use the data dictionary template for the field inventory.
