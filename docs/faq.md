# ❓ Frequently Asked Questions

## What do I need to open the dashboard?
Microsoft Power BI Desktop and the repository's PBIX file.

## Why does Power BI ask for the Excel file?
The report may reference a local workbook path. Inspect the source step in Power Query and reconnect it to the downloaded workbook.

## Is there a live dashboard URL?
No verified public report URL is included. The previous README placeholder was not a usable link.

## What does the dashboard analyse?
The existing project overview describes sales, orders, quantity, monthly comparisons, stores, product categories, daily trends, top-ten products, weekday/weekend comparisons, and day-hour patterns.

## Are exact DAX formulas documented?
Not yet. They must be extracted from the PBIX and validated before being published as exact formulas.

## Is this a website?
No website source code is present in the visible repository. It is a Power BI project with a report and Excel workbook.

## Are Power BI Service refresh and gateway configured?
The repository does not establish that. Inspect the actual Service environment, if one is used.

## Can I use the workbook for other analysis?
Subject to its data license, privacy constraints, and field meanings. Inspect the workbook before redistributing or using the data.
