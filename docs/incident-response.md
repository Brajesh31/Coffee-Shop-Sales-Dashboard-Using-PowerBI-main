# 🚨 Incident Response

## Purpose
Relevant incident classes include publication of sensitive workbook data, exposed credentials, unauthorized workflow changes, tampered PBIX/XLSX artifacts, malicious assets, and materially incorrect KPIs.

## Current project context
Contain by restricting sharing or disabling the affected workflow. Preserve commit hashes, timestamps, logs, and clean artifact copies. Assess exposed data, credentials, affected users, and business impact. Remediate, verify, and communicate through approved channels.

## Recommended workflow
Use the incident-report template. Do not post confidential incident details in public GitHub issues. Follow applicable legal and organizational notification requirements after qualified review.
