# ♿ Accessibility Guidelines

## Purpose
Use descriptive titles and alt text, adequate contrast, labels and units, accessible tables where practical, logical tab order, and colour-independent communication.

## Current project context
The actual report's contrast, alt text, focus order, screen-reader labels, and mobile layouts have not been audited. WCAG 2.2 AA is a useful target for applicable content, not a verified certification.

## Recommended workflow
Test representative analyst journeys in the actual Power BI viewing environment. Record Desktop/browser version, pages tested, assistive technology, findings, severity, and remediation.

## Evidence and verification
Do not claim WCAG conformance from repository text alone. Use the accessibility audit template.
