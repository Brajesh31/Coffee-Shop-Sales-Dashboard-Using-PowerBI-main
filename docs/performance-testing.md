# ⏱️ Performance Testing

## Purpose
Measure report open time, refresh duration, and per-visual rendering time separately using Power BI Performance Analyzer.

## Current project context
No measured baseline is currently published. Results are meaningful only when Power BI Desktop build, device, workbook version, filters, and test method are consistent.

## Recommended workflow
Repeat measurements under the same conditions, record duration and range, and profile the slowest visual/query before optimizing. Confirm optimizations do not change KPI results.

## Evidence and verification
Set thresholds only after collecting a baseline and agreeing on user expectations.
