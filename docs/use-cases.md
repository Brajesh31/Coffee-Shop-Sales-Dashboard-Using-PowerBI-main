# 📝 Use Cases

## Purpose
UC-01 review overall performance. UC-02 compare a selected month with the previous month. UC-03 compare locations using a consistent date context. UC-04 explore category and product mix. UC-05 compare weekdays and weekends. UC-06 inspect the day-hour matrix. UC-07 validate a finding against an independent source calculation.

## Current project context
For every use case, document preconditions, PBIX version, exact page and controls, selected filters, expected output, actual output, and sanitized evidence.

## Recommended workflow
A valid use case must be reproducible by another reviewer. When documenting a click path, use only controls found in the actual report. Record how a user resets filter context if that capability exists.

## Evidence and verification
A top sales result is not proof of profitability. A time concentration is not a demand forecast. A product ranking depends on its selected measure.
