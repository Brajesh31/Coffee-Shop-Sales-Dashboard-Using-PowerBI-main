# 🛠️ Maintenance Plan

## Purpose
Maintenance triggers include source schema changes, reporting-period extensions, KPI changes, visual revisions, Desktop updates, workflow changes, and privacy/security findings.

## Current project context
On source change update data dictionary and preparation docs. On DAX change update KPI definitions and reconciliation. On visual change update page inventory and screenshots. On workflow change review permissions and action versions.

## Recommended workflow
Use the maintenance checklist template. Give each task an owner, priority, evidence, and review date.

## Evidence and verification
Maintenance does not end when documentation is initially created; it continues with report and source changes.
