# 🗃️ Module and Artifact Documentation

## Purpose
Repository modules are artifacts: PBIX report/model, XLSX source workbook, PNG background image, Markdown documentation, SVG diagrams, Python validator, and GitHub issue/workflow configuration.

## Current project context
Power Query queries, model tables, measures, and report pages are internal PBIX modules. They must be inventoried using Power BI Desktop rather than inferred from repository filenames.

## Recommended workflow
For every artifact record purpose, source, format, owner, version, inputs, dependencies, outputs, and validation. For PBIX internals record exact object name, object type, responsibility, relationship or measure dependencies, and evidence.

## Evidence and verification
No frontend component, API controller, database migration, or application service module is currently visible.
