For each feature, record its business question, exact PBIX page, visual inventory, underlying measure, dimensions, default filter context, interaction behavior, interpretation warning, and validation evidence. Page and visual names must be read from the actual PBIX.

Do not claim forecasting, inventory optimization, customer segmentation, profit analysis, or real-time monitoring unless the report is changed and verified.
