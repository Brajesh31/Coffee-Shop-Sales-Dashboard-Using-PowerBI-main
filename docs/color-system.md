# 🎨 Color System

## Purpose
A report color system should distinguish primary data series, comparisons, neutral context, warnings, and positive/negative change without relying on color alone.

## Current project context
The actual report palette has not been extracted. Existing README visuals use a coffee-inspired illustration palette, not a verified report theme.

## Practical process
Document each exact color token, semantic role, approved use, contrast pair, and non-color cue. Check chart series distinguishability and conditional formatting. Provide labels or symbols for status and direction where possible.

## Verification and boundaries
Avoid arbitrary red/green-only meaning, especially in matrices and conditional-format scales.
