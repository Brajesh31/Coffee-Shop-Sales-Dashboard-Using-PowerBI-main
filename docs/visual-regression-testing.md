# 🖼️ Visual Regression Testing

## Purpose
Capture screenshots from the actual PBIX after meaningful visual changes. Use the same window size, page, filters, theme, and data version for comparisons.

## Current project context
No verified report screenshot baseline is currently committed. Existing PNG/SVG files are visual assets and diagrams, not proof of dashboard rendering.

## Recommended workflow
Compare titles, labels, clipping, axes, conditional formatting, blank visuals, and layout. Store approved captures under assets/screenshots with version and filter context. Remove sensitive values first.

## Evidence and verification
Never synthesize a mockup and present it as a real report screenshot.
