# 🔐 Authentication Boundaries

## Purpose
The repository contains no custom application login, registration, password reset, session management, OAuth callback, or authentication code.

## Current project context
Access to GitHub and optional Power BI Service is governed by those products' account and organization settings, not by custom authentication modules in this repository.

## Practical process
If Service publishing is introduced, document tenant identity provider, workspace membership, external sharing constraints, and authentication requirements using approved internal policy. Do not store credentials in the PBIX or public docs.

## Verification and boundaries
No custom authentication feature should be described as implemented.
