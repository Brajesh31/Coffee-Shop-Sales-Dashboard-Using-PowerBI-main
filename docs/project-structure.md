## Important files
- `coffee shop sales.pbix`: report/model artifact.
- `Coffee Shop Sales.xlsx`: source workbook artifact.
- `Background image.png`: existing image asset.
- `README.md`: landing page and navigation.
- `LICENSE`: MIT license text.
- `CITATION.cff`: citation metadata.
- `.github/`: issue forms, review template, automation.
- `docs/`: guides, diagrams, and templates.
- `scripts/`: executable repository validation.

The tree describes repository files, not the uninspected internals of the PBIX.
