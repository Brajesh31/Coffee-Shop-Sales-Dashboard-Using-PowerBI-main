# 🎯 Project Objectives

## Purpose
The project should make historical retail activity easier to explore through a reproducible workbook-to-Power-BI workflow.

## Current project context
The objectives are to present sales, orders, and quantity indicators; support the location, category, product, and time comparisons described by the README; retain the source workbook with the report; explain KPI definitions and limitations; and provide repeatable quality checks before distribution.

## Recommended workflow
Measure progress through independently reconciled KPIs, a repeatable source refresh, understandable visual labels, verified filter behavior, genuine screenshots, and current documentation. Do not use invented user counts, revenue improvements, or speed claims as success criteria.

## Evidence and verification
Report accuracy and reproducibility take priority over adding more visuals. See functional and non-functional requirements.
