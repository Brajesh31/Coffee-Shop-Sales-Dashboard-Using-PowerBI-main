# 🤝 Code of Conduct

## 🌱 Our commitment

This repository aims to be a respectful, constructive place to discuss Power BI, data preparation, DAX, analytics, documentation, and visualization quality.

Everyone participating in project discussions, issues, reviews, and contributions is expected to help create a welcoming environment.

## ✅ Expected behavior

- Be respectful, patient, and constructive.
- Critique technical decisions, not people.
- Explain disagreements with evidence and reproducible examples.
- Respect privacy and do not publish confidential workbook data.
- Give contributors credit for substantial work.
- Keep discussions relevant to the project.
- Report security or privacy concerns privately using the process in [SECURITY.md](SECURITY.md).

## 🚫 Unacceptable behavior

- Harassment, discrimination, threats, or personal attacks.
- Publishing personal information without consent.
- Trolling, deliberate disruption, or repeated bad-faith arguments.
- Posting malicious files, credentials, or harmful links.
- Misrepresenting test results, dashboard capabilities, or data findings.
- Plagiarism or knowingly misleading attribution.

## 🧭 Enforcement

Project maintainers may edit or remove unacceptable content, close unproductive discussions, restrict participation, or block accounts for serious or repeated violations. The response will be proportionate to the behavior and available evidence.

## 📬 Reporting

For conduct concerns, contact the repository owner through the GitHub profile: https://github.com/Brajesh31. Include links, dates, and relevant context. Do not post sensitive personal details in a public issue.

Reports will be handled as discreetly as practical. Retaliation against a good-faith reporter is not acceptable.

## 🔗 Scope

This policy applies in repository spaces and when an individual is representing this project in a public project context.
