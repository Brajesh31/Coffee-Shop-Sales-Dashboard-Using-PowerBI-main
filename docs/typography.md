# 🔤 Typography Guidelines

## Purpose
Typography should make KPI values, chart labels, titles, axes, and notes legible at the report's intended canvas size.

## Current project context
The PBIX font choices and type scale are not inspected. Record actual font family, sizes, weights, and fallback behavior before claiming the report follows a typography system.

## Practical process
Use clear hierarchy: report title, page title, visual title, KPI value, axis/legend labels, and explanatory notes. Avoid excessive uppercase labels and tiny footnotes. Test at fit-to-page and narrow viewing widths where supported.

## Verification and boundaries
Do not alter fonts until checking whether the selected typeface is available in the target Power BI environment.
